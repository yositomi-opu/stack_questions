# STACK Edit WebApp

既存STACK問題の問題名・問題変数・問題文・全般的フィードバックを編集するアプリです。入力欄・既存PRT・未知フィールドは保持します。PRT構造の汎用編集は未対応です。`make stack-edit-webapp` で起動し、localhost:4176を開きます。プレビューには共通のMCQ連携・STACK APIを使用します。

Edit the name, variables, question text and general feedback of existing STACK questions while preserving inputs, PRTs and unknown fields. Arbitrary PRT structure editing is not implemented. Run `make stack-edit-webapp` and open localhost:4176. Preview uses the shared MCQ bridge and STACK API.
