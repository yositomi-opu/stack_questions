# 看護学サンプル

新CSV仕様の看護学（感染対策）サンプル10件です。各問題は5つの命題パターンを持ち、各パターンについて真の場合の文 `C`、偽の場合の文 `W`、共通フィードバックを定義しています。

内容は厚生労働省、CDC、WHOの標準予防策・手指衛生に関する資料を参考にしています。教育利用時は、所属施設の最新マニュアルも確認してください。

- https://www.mhlw.go.jp/topics/2005/02/tp0202-1.html
- https://www.cdc.gov/infection-control/hcp/basics/standard-precautions.html
- https://www.cdc.gov/infection-control/hcp/core-practices/index.html
- https://www.who.int/publications/m/item/five-moments-for-hand-hygiene
