APIキーの取得と登録

確認日：2026年9月23日。各社の画面・料金・利用可能モデルは変更されます。最新情報は以下の公式リンクで確認してください。

APIキーは、このアプリからAIへ翻訳を依頼するための専用の認証情報です。チャット画面にログインするだけでは登録できません。API側の利用条件・料金を確認してください。APIを使わない場合は「ファイルで翻訳」を選べます。

1. 利用するAIのキーを取得

OpenAI（ChatGPTの提供元）

  1. OpenAIのAPIキー管理画面へログインします。
  2. 利用するプロジェクトを選び、APIキーを新規作成します。名前は「STACK MCQ」など、用途が分かるものにします。
  3. 表示されたキーをコピーし、このアプリの「AI設定」に登録します。
  4. API管理画面でBilling・Usage・Limitsを確認し、利用に必要な課金設定と使用量の確認を行います。

公式：開始手順 · モデル一覧 · API料金

Claude（Anthropic）

  1. Claude Consoleへログインし、Settings → API keys → Create key を開きます。
  2. 個人利用では自分に紐づくキーを作り、特定のワークスペースに限定します。このアプリにはワークスペースIDを指定する欄がありません。有効期限も確認します。
  3. キーをコピーして「AI設定」に登録し、ConsoleのBillingで利用可能残高・支出設定を確認します。

公式：キー作成・認証 · 利用開始・課金設定の案内 · モデル一覧

Gemini（Google）

  1. Google AI StudioのAPI KeysへGoogleアカウントでログインします。
  2. プロジェクトとキーを確認し、必要ならCreate API keyで作成します。既存のCloudプロジェクトを使う場合は、Projectsからインポートが必要なことがあります。
  3. AI Studioで作成したキーをコピーし、「AI設定」に登録します。古いキーが拒否される場合は、公式の移行案内を確認し、新しい認証キーを作成してください。
  4. 無料枠の対象モデル・制限を確認します。有料枠が必要ならSet up billingから課金を設定し、Usageで使用量を確認します。無料枠・有料枠のデータ利用条件も確認してください。

公式：キー取得・移行 · 課金設定 · モデル一覧 · 料金・データ利用

2. アプリに登録して翻訳

  1. ローカル版を起動し、http://localhost:4173/を開きます。公開サイトではAPI機能を利用できません。
  2. 「多言語対応」→「AI設定」でサービスを選び、モデルIDとAPIキーを入力して「保存」を押します。
  3. モデルIDには公式一覧のAPI用IDをそのまま指定します。モデルの表示名ではありません。OpenAIのResponses API、ClaudeのMessages API、GeminiのgenerateContent APIで構造化JSON出力に対応し、自分のアカウントで利用可能なモデルが必要です。全モデルでの動作を保証するものではありません。
  4. まず展開言語を1つ選んで「自動翻訳」を実行し、訳文を確認してCSV保存します。設定の「保存」は登録のみで、接続確認や翻訳は実行しません。

キー欄が次回空欄でも、登録済みの表示があれば保存されています。空欄のまま保存すると既存キーを維持します。保存先は実行端末の~/.config/stack-mcq-webapp/ai.json（所有者のみ読書可能、暗号化なし）。CSV・XMLには含めません。「保存キーを削除」は端末内の保存分だけを削除し、各社でのキー失効は行いません。

キーはパスワードと同様に扱い、問題ファイル・GitHub・質問文へ貼り付けないでください。翻訳対象の問題文・選択肢・フィードバックは選択したAIへ送信されます。利用料金は各社の管理画面で確認してください。

うまくいかないとき

  • 401／403：キーのコピー漏れ、有効期限、権限を確認します。
  • 400／404：モデルIDと構造化出力対応を確認します。Claudeではキーのワークスペース指定も確認します。
  • 429：使用量・残高・利用制限を確認し、時間をおいて再実行します。
  • 設定画面が動かない：更新後にmake restartを実行し、localhostで開き直します。
  • 翻訳未完成・検証エラー：原文の埋込構文を確認し、別の対応モデルを試すか「ファイルで翻訳」を利用します。正常に反映された言語は保持されます。

Get and register an API key

Checked September 23, 2026. Provider screens, prices and models change; use the official links above for current details. API access requires its own setup. You can use “Translate via file” without an API key.

Choose a provider

  • OpenAI: Sign in to API keys, select your project and create a key. Copy it into AI settings. Check Billing, Usage and Limits in the API dashboard. See the official quickstart.
  • Claude: In Claude Console, open Settings → API keys → Create key. For personal use, link it to yourself and scope it to a single workspace; this app has no workspace ID field. Check expiration and Billing. See authentication guidance.
  • Gemini: Open AI Studio API Keys, select or create a project and create a key. Existing Cloud projects may need importing. Use newly issued keys if an old key requires migration. Check free-tier eligibility, quotas, data-use terms and billing before upgrading. See key guidance and billing.

Register and try a translation

  1. Open the local app at http://localhost:4173/. API translation is unavailable on public sites.
  2. Open AI settings in the multilingual section. Select the provider, enter its API model ID and your key, then Save. Saving does not test the connection or run a translation.
  3. Use an accessible model supporting structured JSON output through OpenAI Responses, Claude Messages or Gemini generateContent. Copy the API ID from the provider’s model catalog, not its display name. Not every model is supported.
  4. Select one target language, run Auto-translate, review the result and save your CSV.

Keys are stored in ~/.config/stack-mcq-webapp/ai.json on the server computer, owner-readable/writable and not encrypted. They are excluded from CSV/XML. A blank key field preserves the saved key. Removing a saved key does not revoke it at the provider. Never publish keys in problem files, GitHub or prompts. Translation text is sent to the selected provider; check charges in its dashboard.

Troubleshooting

401/403: check key, expiration and permissions. 400/404: check model ID and structured-output support; for Claude, check workspace scope. 429: check balance, quotas and usage, then retry later. After updating the app, run make restart and reopen localhost. For incomplete translations, inspect embedded syntax, try another supported model or use the file workflow. Successfully applied languages are retained.
